BannerHub V6 Normal para Android

Esta edição modificada do BannerHub 6.3.1 mantém o botão + Inject na lista depois da primeira importação. Use-o para adicionar outros drivers ou componentes, como DXVK e FEX. O aplicativo é opcional para quem vai instalar a tradução.

Baixar BannerHub V6 Normal (.apk)

Se você já usa o V6 Normal 1.0.2-631, abra o APK e toque em Atualizar. Se o Android pedir para desinstalar, cancele para preservar seus controles. Depois, abra Banner Tools → Components → + Inject e escolha o próximo arquivo.

Instalação pelo Termux

Use a edição de Windows em inglês com iw5sp.exe e zone/english. Feche o GameHub, reserve cerca de 4 GB livres e salve o ZIP na pasta Download do Android.

Na primeira utilização do Termux, instale o Python e permita o acesso ao armazenamento.

pkg install python
termux-setup-storage

Se o jogo estiver em /sdcard/X360/Call of Duty - Modern Warfare 3, cole o bloco abaixo. Para outra pasta, acrescente --jogo "/caminho/do/jogo" aos dois comandos que executam arquivos .pyz.

cd /sdcard/Download &&
python -m zipfile -e MW3_PTBR_Termux.zip MW3_PTBR &&
python MW3_PTBR/MW3_PTBR_Parte_1_de_2.pyz &&
python MW3_PTBR/MW3_PTBR_Parte_2_de_2.pyz

Quando a segunda parte confirmar a instalação, abra o jogo e ative as legendas nas opções de áudio. Na missão Black Tuesday, procure o título Terça Negra.

Como restaurar os arquivos anteriores

Preserve a pasta de backup dentro de zone/english. Com o jogo fechado, execute os dois instaladores com a opção de restauração. Se usou uma pasta personalizada, informe-a novamente.

cd /sdcard/Download/MW3_PTBR &&
python MW3_PTBR_Parte_1_de_2.pyz --restaurar &&
python MW3_PTBR_Parte_2_de_2.pyz --restaurar
